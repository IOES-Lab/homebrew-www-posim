WWW-POSIM 0.4.5 includes Apple Silicon Mac DMG and application-only updates, Ubuntu AMD64 DEB and Windows x64 EXE installers. The Mac engine includes ROS 2 Lyrical, Gazebo Jetty 10, Metal rendering and surface/underwater Autopilot.

The new LIVE voyage guide explains the WAM-V vehicles, lead/follow control, coastal route checks, cameras, LiDAR, IMU, thrust telemetry and AIS integration. Eight examples are rendered from the actual AIS vessel-model generator. The guide is available in English and Korean. POSIM remains an unchanged source submodule.

The packaged workbench includes the revised documentation and login wording. The engine archive is identical to the previously accepted native core; an application-only update reuses it. The rebuilt DMG passed mounted version, launcher diagnostic and signature checks. Ubuntu and Windows compiled launchers passed installation and diagnostics in platform CI. Their simulator engines use matching Docker images; registry access is required while those images remain private.

Sign in with your email. Account connection is automatic, and startup progress and optional updates remain available. User files and terrain are stored outside the application bundle. Public media are served directly by the simulation origin. Existing feature recordings retain their own capture versions; AIS model examples were rendered for this release.

Mac requirements: Apple Silicon, macOS 27 or later. The development app is ad-hoc signed, not Apple-notarized. Use SHA256SUMS to verify downloaded packages.
